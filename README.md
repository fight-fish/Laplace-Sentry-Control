# 拉普拉斯哨兵控制（Laplace Sentry Control）

個人獨立開發的「目錄哨兵工具」，用來自動產生與更新專案的目錄樹，方便搭配 AI、筆記系統或文件管理。

---

## 功能簡介

- 監看指定專案的真實目錄結構
- 一鍵產生 / 更新目錄樹文件（AUTO_TREE 類型）
- 支援忽略規則（ignore_patterns），可以靜默某些資料夾
- 後端 Daemon + Windows UI，專門給自己用的開發輔助工具

---

## 安裝方式（Windows）

1. **下載安裝包**

   在這個 GitHub 倉庫的根目錄下載：

   `Laplace-Sentry-Control-v1.1.0.zip`

2. **解壓縮**

   建議解壓到類似的位置（可自行調整）：

   `C:\Laplace_Dev\Laplace_Sentry_Control`

3. **執行安裝**

   在解壓後的資料夾裡，找到並執行：

   `install.bat`

   依照指示完成安裝。

4. **啟動程式**

   - 如果安裝有建立捷徑，可以從桌面或開始選單啟動  
   - 或直接在安裝目錄中執行提供的啟動腳本（例如 `run_sentry_ui.bat`，依實際檔名為準）

---

## 系統需求

- 建議搭配 WSL + Ubuntu（若要使用自動更新後端）
